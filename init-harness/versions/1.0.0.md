# 1.0.0 — Initial release

## What changed

First release of `init-harness`: a lightweight, vendor-neutral harness for
small tools. Scaffolds the minimal artifact set (`AGENTS.md` + `CLAUDE.md`
symlink, `ARCHITECTURE.md`, `docs/README.md`, `docs/PLANS.md`,
`docs/exec-plans/active/`, `docs/decisions/` with two ADRs,
`docs/processes/harness.md` + `dev-setup.md`, `docs/tech-debt-tracker.md`,
and one Python plan-coverage validator at `scripts/harness/`).

No Claude/Codex coupling: no subagents, no `.claude/hooks`, no codex
companion script, no model-policy. Enforcement is git pre-commit + the
stdlib-Python plan-coverage check only.

## How to apply

Fresh scaffold — there is no prior version to migrate from. Follow the
scaffold steps in `SKILL.md`. A re-run on an already-1.0.0 repo is a no-op
(every artifact is fill-missing/idempotent).
