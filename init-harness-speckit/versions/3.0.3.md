# 3.0.3 — Hook skills say what they change and when to run them

## What changed

Since 3.0.2 the agent can invoke the `harness-*` skills itself, so each
skill's frontmatter `description` is what it decides from. The two that change
state had one-line descriptions: `harness-implement-lite` executes the plan,
and `harness-loop`'s `closeout` sets `status: completed`. Both now state what
they run, what they change, and when to use them. `harness-gate` and
`harness-verify` only check, and keep their one-liners. Skill bodies are
unchanged.

This skill's own `SKILL.md` description is now single-quoted so it parses as
strict YAML (it contains `: `). That file is not copied into target repos, so
nothing to apply for it.

## How to apply

1. For `harness-implement-lite` and `harness-loop`: in
   `.agents/skills/<name>/SKILL.md` (the `.claude/skills/<name>` symlink points
   at it), if the `description:` line still reads
   `"Execute the active analyzed plan directly without speckit tasks."` or
   `"Run the spec-kit loop termination check."`, replace that one line with the
   `description:` line from `assets/skills/<name>/SKILL.md`. Otherwise leave the
   file alone. Change nothing else in the file.

2. **Advance `.harness-version` to `3.0.3`.** No `doctor` invariant changed.
