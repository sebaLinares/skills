# 3.0.2 — The agent may invoke the harness-* skills itself

## What changed

The four hook skills (`harness-gate`, `harness-implement-lite`,
`harness-loop`, `harness-verify`) no longer carry
`disable-model-invocation: true` in their frontmatter. Before, only the human
could trigger them by name; now the agent can invoke them on its own when the
flow calls for it (e.g. running the gate or the verify command). The skill
bodies are unchanged. This shipped in commit `d466fa3` without a version bump;
this release records it so repos at 3.0.1 pick it up.

## How to apply

1. For each of `harness-gate`, `harness-implement-lite`, `harness-loop`,
   `harness-verify`: open `.agents/skills/<name>/SKILL.md` (the
   `.claude/skills/<name>` symlink points at it). If its frontmatter contains
   the line `disable-model-invocation: true`, delete that line; otherwise
   leave the file alone. Leave everything else in the file unchanged.

2. **Advance `.harness-version` to `3.0.2`.** No `doctor` invariant changed.
